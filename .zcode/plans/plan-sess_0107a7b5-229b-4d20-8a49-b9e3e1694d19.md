# fans-tracker：多平台社媒账号数据追踪 + 腾讯文档自动填报

## 目标
每天早上 9:00 自动抓取各平台账号的**累计粉丝 / 内容数 / 累计阅读播放量**，自动计算增粉与环比，写入腾讯文档《AI-IP社媒数据统计》（file_id=`DQU9YSmROcG9jWHNW`）中**以当日日期命名的新 sheet**，沿用表内现有 9 列模板：

```
账号所有人 | 所属平台 | 账号名称 | 阅读/播放量 | 内容数 | 增粉 | 环比上周 | 累计粉丝 | 上周增粉数据
```

## 已确认决策
- 公众号、视频号：**本期跳过**（微信封闭生态需后台权限，代码留 fetcher 接口位）
- YouTube：Google Data API v3（你已有 key 稍后提供，先留 `.env` 配置位，未配置时该平台优雅跳过）
- 阅读/播放量口径：**累计总量**（公开页可得）
- 首批测试账号：auto-publisher 已验证的自账号主页（富途/雪球/长桥/东方财富/微博）
- 抓取失败的账号/指标在表格中标 `-`，不阻塞其他账号；本地留失败截图和日志

## 项目结构（新建 D:\AI\fans-tracker，Python + Playwright，与 auto-publisher 同栈）

```
fans-tracker/
├── main.py              # CLI: crawl / login <平台> / sync / status
├── config/
│   ├── accounts.yaml    # 账号清单：平台 / 账号所有人 / 账号名称 / 主页URL / @handle
│   └── settings.yaml    # 浏览器模式(CDP优先)、重试、腾讯文档 file_id、抓取时间
├── .env                 # YOUTUBE_API_KEY（gitignore）
├── fetchers/
│   ├── __init__.py      # 平台注册表（公众号/视频号预留接口位）
│   ├── x_fxtwitter.py / youtube_api.py / bilibili_api.py
│   └── browser_page.py  # SPEC 驱动的通用主页抓取（其余全部平台）
├── browser.py           # CDP 接管(9222)优先，回退持久 profile（复用成熟模式）
├── history.py           # data/history.json 逐日快照（原子写，增粉计算的数据底座）
├── metrics.py           # 增粉=今日-昨日；上周增粉=7天前-14天前；环比上周=本周vs上周增粉
├── tdoc.py              # 腾讯文档写入（MCP over HTTP / mcporter；token 已配好已验证）
├── login.py             # 需登录平台的一次性扫码，存 profiles/<平台>/
├── run_daily.bat        # 计划任务入口
└── logs/                # 运行日志 + 失败截图
```

## 数据流（每天一次）
`accounts.yaml` → 逐账号调对应 fetcher（失败重试 1 次后标 `-` 并截图）→ 写入 `history.json` 当日快照 → metrics 计算衍生列 → tdoc：当天日期 sheet 不存在则 `add_sheet(name=2026-09-18)`，CSV 批量写入表头+数据行 → 输出汇总日志。幂等：当天已成功同步则跳过。

## 自动化
Windows 计划任务 `schtasks /SC DAILY /ST 09:00` 调 `run_daily.bat`；另加一个「登录时触发」补跑（脚本幂等，9 点关机漏跑后开机自动补）。

## 实施步骤
1. 项目骨架 + accounts.yaml（预填自账号）+ history/metrics/CLI
2. 三个 API 路线（X / YouTube / B站）——不依赖浏览器，先跑通出真数据
3. 通用浏览器抓取器：移植 followers.py 核心，富途/雪球/长桥/东财实测 + 内容数/阅读量扩展
4. 其余平台逐个真实页面探测调 selector（老虎/同花顺/新浪财经/快手/小红书/抖音）
5. tdoc 对接：先写测试 sheet 验证再删，然后实现当天 sheet 逻辑
6. 端到端真实跑一天数据，人工核对腾讯文档结果
7. 注册计划任务 + README（账号清单填写说明 / 扫码登录指南 / key 配置）
8. git init + 推送到 github.com/1375692655hzh/fans-tracker（gh 未登录则先留在本地）
